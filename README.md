# 🌦️ Weather Finder App (React)

A modern and responsive **Weather Finder application** built using **React**, **Axios**, and **Tailwind CSS**.  
This app allows users to search for any city and instantly get **real-time weather information**.

## 📌 Project Overview

The **Weather Finder App** fetches live weather data from the **OpenWeatherMap API** and displays:

- Current temperature
- Humidity level
- Wind speed
- Weather condition icon

The UI is clean, modern, and fully responsive.

---

## ✨ Features

- 🔍 Search weather by **city name**
- 🌡️ Displays **temperature in Celsius**
- 💧 Shows **humidity**
- 💨 Shows **wind speed**
- 🎨 Beautiful **glassmorphism UI**
- ⚡ Fast API fetching with Axios
- 📱 Fully responsive (mobile friendly)
- ❌ Error handling for invalid cities

---

## 🛠️ Technologies Used

- **React (useState, functional components)**
- **Axios** – API requests
- **Tailwind CSS** – Styling
- **React Icons**

## 🌍 API Used

**OpenWeatherMap – Current Weather API**

https://api.openweathermap.org/data/2.5/weather


### Example:
https://api.openweathermap.org/data/2.5/weather?q=London&units=metric&appid=YOUR_API_KEY


✅ Free tier  
✅ HTTPS supported
